## Code Snippets

You can display `inline code` by wrapping text in single backticks. 

For larger sections of code, use a fenced code block with three backticks before and after. You can add a language identifier (like `javascript` or `python`) right after the first set of backticks to enable syntax highlighting:

```javascript

    console.log("Hello, " + name + "!");
}
greetUser("World");
```
